MedGemma 1.5 4B -- fixed prompt templates (one per dataset; run_medgemma.py variant "G"), fixed on training-pool
scans before the first evaluation run.

Message structure (CT notebook, high_dimensional_ct_hugging_face.ipynb): one user turn whose content is
  [text: INSTRUCTION] + for k = 1..n: [image: slice k as a JPEG data URL] [text: "SLICE k"] + [text: QUERY]
processor.apply_chat_template(add_generation_prompt=True, continue_final_message=False, tokenize=True,
return_dict=True); greedy decoding (do_sample=False), max_new_tokens=2000 (the notebook's settings).
The chat template trims each text item and concatenates items without separators (as in the notebook).
The location format (x, y normalized to [0, 1000]; "Instructions: ... You MUST output a single parseable json ...
Now answer to the user query. / Query: ... Don't give a final answer without reasoning. Output the final answer in the
format "Final Answer: X" ... Answer:") is MedGemma's own localization prompt (cxr_anatomy_localization_with_hugging_face
.ipynb), adapted from a box to a point (SLICE, x, y) plus a diameter.
Per-case fields (geometry only): {n} = number of fed slices (85, or all if fewer), {dz} = mean spacing between fed
slices in mm, {fov} = 512 x pixel spacing in mm, {px} = in-plane pixel spacing in mm.

=== LUNA16: INSTRUCTION
You are a radiologist reviewing a chest CT scan. You are given {n} axial CT slices ordered from superior (SLICE 1) to inferior (SLICE {n}), about {dz:.1f} mm apart; each slice image covers {fov:.0f} mm x {fov:.0f} mm ({px:.2f} mm per pixel). Please review the slices provided below carefully.

Instructions:
The following user query will require outputting the location of a finding in the CT slices below. The location is the SLICE number on which the finding appears largest and the x and y coordinates of its centre on that slice. Always normalize the x and y coordinates to the range [0, 1000], meaning that a point at 15% of the image width would be associated with an x coordinate of 150, with x measured from the left edge and y from the top edge of the image. You MUST output a single parseable json object enclosed in ```json...``` brackets, with the keys "present" (true or false), "slice" (SLICE number), "x", "y" and "diameter_mm" (diameter in millimetres). Now answer to the user query.

block and LaTeX brace escapes; first JSON object after the last "Final Answer", else the last JSON object; without JSON,
